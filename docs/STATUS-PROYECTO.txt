1. RESUMEN EJECUTIVO
================================================================================

AIDA es una plataforma SaaS de facturación electrónica e imprenta digital
para Venezuela, conforme con las regulaciones del SENIAT. Arquitectura
multi-tenant con 6 portales web, API fiscal estándar, y motor de emisión
de documentos.

Tecnologías:
  - Backend:  Python 3.12 + FastAPI + SQLAlchemy 2.0 (async) + PostgreSQL 16
  - Frontend: Next.js 15 + TypeScript + Tailwind CSS (Turborepo monorepo)
  - Cache:    Redis 7
  - AI:       Groq API (llama-3.3-70b-versatile)
  - PDF:      ReportLab
  - Deploy:   Vercel (frontend) + Railway (backend) + Neon (DB) + Upstash (Redis)

Estadísticas del codebase:
  - Backend:  ~26,000 líneas Python en 80+ archivos
  - Frontend: ~6,200 líneas TypeScript/TSX en 6 aplicaciones
  - Modelos:  40 tablas de base de datos
  - Endpoints: 17 módulos de API
  - Total:    ~32,000 líneas de código
