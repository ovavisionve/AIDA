1. RESUMEN EJECUTIVO
================================================================================

AIDA es una plataforma SaaS de facturacion electronica e imprenta digital
para Venezuela, conforme con las regulaciones del SENIAT. Arquitectura
multi-tenant con 7 portales web (6 funcionales + 1 landing), API fiscal
estandar, motor de emision de documentos, y asistente IA integrado.

Tecnologias:
  - Backend:  Python 3.12 + FastAPI + SQLAlchemy 2.0 (async) + PostgreSQL 16
  - Frontend: Next.js 15 + TypeScript + Tailwind CSS (Turborepo monorepo)
  - Cache:    Redis 7
  - AI:       Groq API (llama-3.3-70b-versatile) / Anthropic / OpenAI
  - PDF:      ReportLab + WeasyPrint
  - Deploy:   Vercel (frontend) + Railway (backend) + Neon (DB) + Upstash (Redis)

Estadisticas del codebase:
  - Backend:  ~26,000 lineas Python en 80+ archivos
  - Frontend: ~7,000 lineas TypeScript/TSX en 7 aplicaciones
  - Modelos:  40 tablas de base de datos
  - Endpoints: 121 endpoints en 20 modulos de API
  - Tests:    44+ tests automatizados
  - Total:    ~33,000 lineas de codigo
